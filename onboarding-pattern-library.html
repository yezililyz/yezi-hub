01

First Look

A welcome modal—slides or a highlight-reel video—shown the first time a user signs up or logs in, sitting on top of a dimmed app to give a high-level overview.

Best forGreat when users need a bird's-eye view of a workspace before diving in.
UI elementsTitle · close button · dimmed backdrop · slides with dots/progress · next button · optional embedded video.
ExamplesIntercom (carousel), Matter (storyboard), Amplitude (video), Slack, Notion, Canva, HubSpot.
ProductivityCreativeSaaS
02

Product Tour

A step-by-step guided walkthrough that points out core features via overlays and popups, moving the user around the interface in a set sequence.

Best forBest for feature-rich or data-heavy platforms that would overwhelm a cold-start user.
UI elementsSequential overlays · highlighted regions · tooltips/carousel · 'Step X of N' · next button.
ExamplesIntercom, Google Analytics, Amplitude, Asana, ClickUp, Salesforce.
AnalyticsSaaSProject mgmt
03

Walkthrough Beacons

Glowing, pulsating indicators placed in the UI that the user can choose to click—drawing attention without forcing a walkthrough.

Best forWhen you want gentle, optional nudges that never lock the app down.
UI elementsSmall pulsating dot · subtle animation · popover tooltip with a brief message · resumable position.
ExamplesSimple (website builder), Webflow, Figma, Canva, Shopify, Squarespace.
CreativeWebsiteSaaS
04

Empty State

An illustration plus instructions shown where there's no content yet, with a call-to-action that launches the user into their first task.

Best forAnywhere the product depends on user-generated content and the canvas starts blank.
UI elementsIllustration · short instructions · primary CTA button to create the first item.
ExamplesTally (forms), Trello, Notion, Todoist, Monday, Pinterest.
ProductivityProject mgmtUser content
05

Personalization

A quick capture of user preferences—topics, interests, categories—so the product can tailor the experience from the first session.

Best forWhen you want to show users only what matters to them on arrival.
UI elementsSelection chips · checkboxes/dropdowns · sliders/toggles · progress bar · optional avatar setup.
ExamplesReddit (interest chips), TikTok, news aggregators, streaming apps.
SocialMediaStreaming
06

Checklist

A simple list of setup tasks the user completes, each checking off with visible progress as they go.

Best forSetup-heavy products where getting to value needs several concrete steps.
UI elementsTask rows · checkboxes · progress bar/percentage · action link per item.
ExamplesFront (setup guide), QuickBooks, Slack, Shopify, CRM onboarding.
SaaSProductivitySetup-heavy
07

Action-Oriented

Like a checklist, but each step prompts a real key action—do the thing, not just read about it—often with a success/celebration moment.

Best forWhen a primary action is the fastest path to the product's 'aha' value.
UI elementsBold CTA · direct 'do this now' language · in-context nudges · completion celebration.
ExamplesCopilot (create a test client), Google Docs, Dropbox Paper, Loom, Grammarly.
ProductivitySaaSCollaboration
08

Goal Setting

Helps users define a goal (e.g. a weekly target) and track progress, encouraging them to keep a streak.

Best forProducts that rely on repeated usage and where success is measurable over time.
UI elementsGoal selector (dropdown/survey) · streak counter · progress visualization · gamified steps.
ExamplesDuolingo, fitness & wellness apps, habit trackers, personal development.
LearningFitnessHabit
09

Coach Marks

Small pointers or highlights on buttons/sections—like digital sticky notes—offering a short explanation when (and if) the user needs it.

Best forSurfacing help the first time a feature is explored, not just at first login—'nurturing onboarding over time.'
UI elementsPointer/tooltip on an element · short description · sometimes a do-it-to-dismiss step.
ExamplesCanva (text tool), Photoshop, design tools that ship new features regularly.
CreativeDesignSaaS
10

Demo Content

A sample dataset or demo project users can play with to feel how the workspace works—without creating anything from scratch.

Best forHelps visual learners and tools where a blank start is intimidating.
UI elementsPre-loaded sample project · 'demo' label · fully interactive sandbox content.
ExamplesFrame.io (demo project), data-analytics tools, video editors.
AnalyticsCreativeEditing
11

Simulation

An interactive or recorded demonstration of the product working under realistic conditions—a private 'playground' that mirrors what end-users will see.

Best forComplex products the customer must configure for their own users.
UI elementsRealistic recreation of the live experience · clear 'tutorial/testing mode' framing · guidance.
ExamplesIntercom (try the messenger), Zendesk, Zoom, Slack, Salesforce.
SupportSaaSCollaboration
12

Self-Segmentation

Asks the user to pick a path or user type ('I'm a teacher / a student') so the rest of onboarding can be tailored to them.

Best forProducts serving multiple distinct audiences or use cases.
UI elementsChoice screen · visual cards or dropdown · loads tailored templates/content after selection.
ExamplesNotion (use-case cards), HubSpot, MailChimp, multi-purpose tools.
ProductivityEnterpriseEducation
13

Contextual Tooltips

Popup tips that appear exactly when a user hovers/clicks something needing explanation—shown at the moment of need, only inside specific workflows.

Best forComplex tools with hidden or secondary features that shouldn't clutter the default view.
UI elementsSmall boxes with a sentence or two · arrow/pointer · sometimes inside flow-specific UI.
ExamplesTrello, Airtable, data-visualization dashboards.
SaaSDataComplex
14

Just-In-Time Modal

A modal that appears exactly when relevant—deeper than a tooltip—when someone does something for the first time that needs a bigger explanation or choice.

Best forFirst-time multi-step actions (e.g. exporting) where the user needs to choose among options.
UI elementsContextual modal · option list/setup prompt · short coaching · first-time trigger.
ExamplesMiro & Canva (export image options).
CreativeSaaSEditing
15

Information Gathering

BONUS

Front-loaded collection of the info a product needs to function—often legally required—frequently combined with other patterns. (Bonus pattern.)

Best forApps that can't deliver value without extensive setup or third-party connections.
UI elementsMulti-step forms · security/legal fields · account/bank linking · progress indicator.
ExamplesAcorns (investor profile, bank link), accounting/finance, HR, Etsy personalization.
